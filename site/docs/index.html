Overview

Jimmy runs in the background on your PC. It reads the text of the window in front of you, transcribes speech near your mic, and keeps both as one searchable history with a blurred screenshot for each moment. When you say "Jimmy, …", it searches that history, shows you what it found, and answers out loud.

Jimmy has two halves:

  • A Python program (ambient and jimmy) that captures, stores, searches and talks to a language model.
  • An overlay: a small pill at the top of your screen, plus cards and answers, built with Electron. The Python program starts it for you.

A one-click Windows installer is being built but is not released yet. For now, install from source with the steps below.

What you need

ItemWhy
Windows 11Screen capture and window text use Windows-only interfaces (DXGI and UI Automation).
An NVIDIA GPUSpeech recognition (Whisper) runs on it. Jimmy was built on an RTX 4050 with 6 GB of memory, which is enough.
Python 3.12Not 3.13 or 3.14: the machine-learning packages Jimmy uses don't install there yet.
Node.js (LTS)To build the overlay once.
OllamaRuns two small local models: one decides cards, one powers search by meaning.
A mic, and optionally a webcamThe webcam is only for the privacy curtain (it draws itself when you walk away).

The packages and models take several gigabytes. Captures then take roughly 30–85 MB per active hour.

Get the code

On the project's GitHub page (the View on GitHub button on the home page), choose Code → Download ZIP and unzip it to C:\Jimmy. If you use git, clone it to the same place instead. A short path avoids Windows' path-length problems.

Open PowerShell and go to that folder. Every command on this page runs from there:

cd C:\Jimmy

Packages and overlay

  1. Make a Python 3.12 environment and install the packages:
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

If py -3.12 says it can't find Python 3.12, install it from python.org and open a new PowerShell window.

  1. Build the overlay once (and again only if you change its code):
cd overlay; npm install; npm run build; cd ..

Local models

With Ollama installed and running, pull the two models Jimmy uses on your PC:

ollama pull qwen2.5:3b
ollama pull bge-m3

qwen2.5:3b answers one yes/no question per possible card. bge-m3 turns text into vectors, so "consulting application" can find a page titled "McKinsey Forward". Whisper's speech model downloads by itself on the first run.

Model key (optional)

Spoken answers come from a cloud model. Pick one provider. Without any key, Jimmy still works: each answer shows what search found instead.

NVIDIA (default, free)

Make a key at build.nvidia.com, then:

setx NVIDIA_API_KEY "nvapi-your-key-here"

Google Gemini (free tier)

Make a key at aistudio.google.com. Create a file named .env in the Jimmy folder with these lines, plus your NVIDIA key, which answers whenever Gemini's free quota runs out or it is down:

GEMINI_API_KEY=your-key-here
JIMMY_PROVIDER=gemini

Google may let reviewers read what is sent on its free tier. Screenshots stay with NVIDIA unless you also add JIMMY_GEMINI_SCREENSHOTS=1.

OpenAI (paid)

OPENAI_API_KEY=sk-your-key-here
JIMMY_PROVIDER=openai

Keep keys in .env or your environment, never in a file you share. Git already ignores .env.

Check and run

.\.venv\Scripts\python.exe -m ambient doctor
.\.venv\Scripts\python.exe -m ambient run

doctor checks every part and asks you to speak for 3 seconds to prove the mic hears you. run starts capture and opens the overlay; quit with Ctrl + C or the pill's Quit. Only one ambient run can go at a time.

Just want to see it first? .\.venv\Scripts\python.exe -m ambient run --demo plays a spoken, scripted tour of about 3 minutes that uses real capture, search, model and voice.

Two one-time steps make it work better for you: say "Jimmy, eye calibration" (about 20 seconds, guided on screen) so you can ask without the name by looking at the screen, and "Jimmy, remember my face" so the curtain knows you.

What you can say

Start with "Jimmy,". After it answers, keep talking for 10 seconds without the name; "thanks" ends it. Say just "Jimmy" to think first: it answers "Yes?" and listens. To type instead, press Ctrl + Alt + Space.

Exclusions

Password managers, banking and payment sites, private browser windows and Jimmy's own windows are never captured. To add your own, create data\exclusions.txt in the Jimmy folder with one rule per line, by program, window title or address:

exe:mysecret.exe
title:payroll
url:internal\.example\.com

Command line

Everything here runs with .\.venv\Scripts\python.exe -m … from the Jimmy folder.

CommandWhat it does
ambient search "consulting application on Friday"Search your history by keywords and meaning, inside any time you name
ambient forget "1 to 15 September"Shows what would be deleted, then asks
ambient compactGives deleted space back (also runs by itself while you're away)
ambient indexBuilds meaning search for older captures
ambient statsHow much is stored
ambient run --no-overlayCapture with the terminal only
jimmy chatTalk to Jimmy in the terminal; /context shows exactly what was sent
jimmy doctorChecks the key, model and endpoint
jimmy trace -n 20The decision log: what Jimmy heard, decided and did
jimmy focus "finish the essay"States an intent, which turns on focus nudges

Ask Jimmy from another assistant (MCP)

python -m jimmy mcp is a small MCP server (Model Context Protocol, the standard way assistants connect to tools) with exactly one read-only tool, recall. Claude Desktop, VS Code and others can ask "what was I reading yesterday?" and get the evidence Jimmy would use, capped at 6,000 characters and marked as data. It can't press, type or change anything. In Claude Desktop's claude_desktop_config.json:

{
  "mcpServers": {
    "jimmy": {
      "command": "C:\\Jimmy\\.venv\\Scripts\\python.exe",
      "args": ["-m", "jimmy", "mcp"],
      "env": { "PYTHONPATH": "C:\\Jimmy" }
    }
  }
}

Whatever recall returns goes to that assistant, and from there to its own cloud model.

Optional extras

Jimmy runs without any of these. Each is a setting in ambient\config.py, whose comment says what to measure before leaving it on.

Troubleshooting

You seeWhat to do
pip fails building packagesCheck that the environment is Python 3.12: .\.venv\Scripts\python.exe --version. Delete .venv and make it again with py -3.12.
Jimmy is already running (another `ambient run`)Quit the other one first, from its pill or its terminal.
The mic test hears near-silenceWindows' noise suppression can make a quiet room read as zero. Speak during doctor. To use another mic, set MIC_DEVICE in ambient\config.py to part of its name.
The overlay never appearsIf overlay\node_modules\electron\dist\electron.exe is missing, run node node_modules/electron/install.js inside overlay.
Answers list search results instead of speakingNo key was found. Run jimmy doctor; after setx, the key works without restarting.
Asking without the name stops workingAnother app (Discord, Teams, Zoom) is holding the mic, which Jimmy treats as a call. Say "Jimmy, I'm not on a call".
net_impl_backend ... Targets are not supportedHarmless noise from OpenCV on import. Ignore it.

Current limits

  • Windows 11 and an NVIDIA GPU only, and built and measured on one laptop.
  • No installer yet. Setup is from source.
  • No automatic retention limit. Captures grow by roughly 30–85 MB per active hour until you forget a span.
  • Hindi accuracy is not measured on real speech yet.
  • Canvas apps and video give no text unless you install Windows OCR, and the vision models a free key can reach describe pictures less exactly than a window's text.
  • Gemini 3.8 Flash on the free tier was often unavailable when measured; Jimmy falls back to 3.5 Flash-Lite and then NVIDIA.
