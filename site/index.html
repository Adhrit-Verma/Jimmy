An always-on assistant for Windows 11

Remembers what you saw. Speaks only when asked.

Jimmy turns your screen's text and the speech near your mic into one searchable history on your own PC. Say "Jimmy, …" and it answers out loud, beside the moments it found. The rest of the time, it stays quiet.

The idea

Built for six good interruptions an evening

Capturing everything is the easy part. What matters is deciding when to stay quiet. Jimmy shows at most 4 cards an hour, never two within 10 minutes, and goes quiet for 30 minutes after you dismiss one. Most hours produce no card at all.

  1. 09:12

    You sit down. The privacy curtain lifts when the webcam sees you facing the screen.

    RESUMELeft off: Fellowship essay · draft 2
  2. 11:40

    Deep in VS Code. Jimmy is capturing and indexing, silently.

    no card
  3. 13:31

    You open a form. It links what's on screen to a concrete earlier moment.

    RECALLSame Northwind Fellowship as Tue 15:02
  4. 14:05

    "Jimmy, when does it close?" It searches Tuesday by meaning and answers out loud.

    spoken answer
  5. 15:30

    You drift to YouTube. You said "focus on the essay" earlier, so one nudge, then 45 minutes of quiet.

    FOCUSBack to: the essay
  6. 16:02

    You step away. The curtain comes down: no capture, no listening.

    resting
  7. 21:00

    Wrapping up. Ask "how was my day?" for the chart.

    RECAPToday: 10h 42m, mostly VS Code

An illustrative day with invented names. Card kinds and limits are the real ones from the code; every card line is written by code from words in your own data, never by a model.

How it works

Capture locally. Ask out loud. Approve what it does.

1

Capture

When the screen changes, Jimmy reads the window's exact text through Windows' accessibility interface (UI Automation) and transcribes speech near your mic with Whisper, on your GPU. Faces are blurred before a screenshot is written.

every 2 s, only if pixels moved
text    from UI Automation
speech  Whisper, local
faces   blurred before the write
store   SQLite on your PC
2

Ask

Say "Jimmy," then your question, in English or Hindi. It searches by keywords and by meaning inside the time you name, shows the moments it used, and speaks the answer.

heard   "…on Tuesday?"
route   recall
search  keywords + meaning
        → evidence in ~0.5 s
speak   from the first sentence
3

Act

Ask it to do something on screen. It plans a few steps, a policy in code checks each one, and its own cursor presses and types through UI Automation, never your mouse. Each step is checked before the next.

plan    type "CarryMinati" in Search
        press Enter
policy  allow · allow
check   ✓ box holds the text
        ✓ page changed

Privacy by construction

Absent code paths, not settings left off

Each of these is enforced in code, and most are checked by a test. What is stored, what leaves your PC, and what is not done yet →

  • Faces blurred before anything is writtenA test re-runs the face detector on the saved JPEG and requires zero hits. The clean frame never reaches disk.
  • Sensitive windows are never capturedPassword managers, banking and payment sites, private browser windows and Jimmy's own windows. The list shipped before the first run, and you can add to it.
  • No faces table, no people tableNeither exists, and a test asserts it. The webcam recognises only you, and only if you ask it to.
  • No raw audio, no system audioOnly transcripts are kept. The far end of a call is never recorded, and the mic pauses on sensitive screens.
  • Captured text is treated as dataIt reaches the model only inside a context block, under a rule to ignore any instructions found there.
  • Rules for actions live in codeEvery proposed action passes a policy layer that refuses, stops, asks or allows, whatever model proposed it.

Get started

Install from source

You need Windows 11, an NVIDIA GPU (built on a 6 GB RTX 4050), Python 3.12, Node.js and Ollama. A one-click installer is in progress and not released yet.

1

Install

Make a Python 3.12 environment, install the packages, and build the overlay once.

py -3.12 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
cd overlay; npm install; npm run build
2

Pull two local models

One decides cards; the other powers meaning search. Both run on your PC through Ollama.

ollama pull qwen2.5:3b
ollama pull bge-m3
3

Check, then run

Add a free model key for spoken answers, or run without one: answers then show what search found.

python -m ambient doctor
python -m ambient run

FAQ

Questions

Does Jimmy send my screen to the cloud?

Not continuously. Captures are stored on your PC. When you ask a question, the evidence shown with the answer (at most 6,000 characters) goes to the model provider you chose. A question about your screen also sends that window's latest picture, with faces already blurred. Without a key, nothing is sent. The full list.

Does it work without an API key?

Yes. Capture, search, the timeline, insights and cards all run locally. Without a key, each answer shows what search found (exactly what would have been sent to the model) instead of a spoken reply.

Which model providers does it support?

NVIDIA (the default; a free key from build.nvidia.com), Google Gemini on its free tier with NVIDIA as a backup, or OpenAI (paid). Card decisions and meaning search always run locally through Ollama.

Does it record other people?

The mic hears the room, so speech near it is transcribed. System audio, such as the other side of a call, is never captured. Faces in screenshots are blurred, only counts are kept, and the webcam recognises only you, and only after you say "remember my face".

Can it click and type on its own?

Only when you asked, it is sure which control you meant, and the action can be undone. It shows its cursor first and gives you a moment to say "stop". Anything that can't be undone, or a site you didn't name, waits for your "yes". It never types into a password box or acts in banking or password-manager windows.

Which languages does it understand?

English and Hindi. Hindi works through one model call that also returns the English; its real-world accuracy has not been measured yet.

Is there an installer?

Not yet. A Windows installer is being built; until it is released, install from source with the setup guide.

Is it open source?

Yes, MIT licensed. The code, every design decision and the evidence behind it are public (View on GitHub, above).
